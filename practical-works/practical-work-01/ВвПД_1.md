## 2. Коммуникация и правила взаимодействия

Основным каналом оперативной коммуникации выбран закрытый командный чат в Telegram.

Каждый участник публикует краткий статус по своим задачам до 11:00: выполнено, в работе, препятствия и следующий шаг.

Планирование этапов и обсуждение архитектурных решений проводятся на согласованных командных встречах; итоги и принятые решения фиксируются письменно.

На важные рабочие сообщения участники отвечают в течение двух часов рабочего дня. Если ответ требует больше времени, отправитель сообщает ожидаемый срок.

Изменение сроков и приоритетов согласуется с руководителем разработки и отражается на доске задач.

Задача считается завершённой, когда выполнены заранее согласованные критерии готовности, а результат доступен команде.

Общение ведётся уважительно и предметно; проблемы и риски сообщаются заранее, без персональных обвинений.

## 6. Матрица распределения ответственности RACI

R (Responsible) — исполнитель задачи; A (Accountable) — лицо, отвечающее за итоговый результат; C (Consulted) — консультируемый участник; I (Informed) — информируемый участник. Для каждой задачи назначен один A.



| Задача | Руководитель | Архитектор | Программист | Тестировщик | Спец. по данным | Исследователь | Документация |

| Формирование команды | A/R | C | C | C | C | C | C |

| Выбор каналов коммуникации | A/R | C | C | C | C | C | R |

| Анализ рынка и требований | C | C | I | I | C | A/R | C |

| Проектирование архитектуры | C | A/R | C | I | C | C | I |

| Разработка функционала | C | C | A/R | I | C | I | I |

| Анализ данных и моделей | I | C | C | I | A/R | C | I |

| Тестирование системы | I | C | C | A/R | I | I | I |

| Подготовка отчёта и сдача | A | C | R | R | R | R | R |



## 7. Вывод

В ходе работы сформирована команда «Ни шагу вперед», определены каналы коммуникации и правила взаимодействия, распределены профессиональные роли и описаны ожидаемые вклады участников. Для каждой роли подобраны профессиональные стандарты и выделены основные трудовые функции. Матрица RACI фиксирует распределение ответственности по ключевым задачам и помогает определить исполнителей, ответственных за результат, консультируемых и информируемых участников. Для окончательной версии отчёта необходимо уточнить официальные реквизиты профессиональных стандартов и выбрать один инструмент ведения задач.
