# Матрица RACI

**Проект:** Сервис рекомендаций фильмов по настроению
**Команда:** <Ни шагу вперед>

Матрица RACI показывает, кто за какую задачу отвечает. Она составлена для задач первого этапа проекта (формирование команды и ролей) и для задач по работе с Git-репозиторием (второй этап).

---

## 1. Обозначения

| Буква | Значение | Что это значит |
|---|---|---|
| **R** (Responsible) | Исполнитель | Выполняет задачу |
| **A** (Accountable) | Ответственный за результат | Отвечает за итог и принимает работу. Для каждой задачи он **только один** |
| **C** (Consulted) | Консультируемый | С ним советуются до и во время работы |
| **I** (Informed) | Информируемый | Его только уведомляют о результате |

Запись **A/R** означает, что один и тот же человек и отвечает за результат, и сам выполняет задачу.

## 4. Пояснения к распределению

- **Руководитель разработки (Синдеев А. С.)** отвечает за результат (A) почти по всем задачам: он следит за сроками, принимает работу и отвечает перед преподавателем за итог. По задачам, где он сам выполняет работу (создание репозитория, слияние веток), он указан как A/R.
- **Специалист по документации (Зинченко В. Г.)** выполняет (R) задачи, связанные с оформлением: отчёты, правила взаимодействия, размещение документов в `docs/` и обновление `README.md`.
- **Архитектор (Черемисин К. Е.)** помогает руководителю с репозиторием: настраивает структуру, поддерживает порядок в папках и проверяет Pull Request'ы.
- **Специалист по тестированию (Боголюбский М. С.)** участвует в проверке отчёта перед сдачей: смотрит на документ свежим взглядом и находит ошибки и пропуски.
- **Исследователь (Насирли Ф. С.)** вместе со специалистом по документации участвует в составлении правил взаимодействия, так как они опираются на потребности команды.
- Задачи, которые касаются каждого (профстандарты, эссе, регистрация на GitHub, коммиты, отчёты по своим разделам, резервное копирование), выполняют все участники (R), а за результат отвечает руководитель (A).

## 5. Проверка правил RACI

- Для каждой задачи назначен **ровно один** ответственный за результат (A).
- Для каждой задачи назначен **как минимум один** исполнитель (R).
- Распределение по работе с Git соответствует методичке: создание репозитория, проверка Pull Request'ов и слияние веток выполняют руководитель и архитектор, остальные задачи выполняют все участники, а ответственным за результат остаётся руководитель.

## 6. Вывод

Матрица RACI закрепляет ответственность за каждой задачей первых двух этапов проекта: у каждой задачи есть исполнитель и один ответственный за результат, а остальные участники знают, когда нужно консультировать и когда ждать информации. Это помогает избежать ситуации, когда задача «ничья» или за неё отвечают сразу несколько человек. Матрица будет дополняться по мере выполнения следующих этапов проекта.
