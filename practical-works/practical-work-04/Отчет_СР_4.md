Цель работы

Сформировать перечень возможных функций сервиса, сгруппировать идеи и определить приоритетные функциональные требования.

1. Организация мозгового штурма

Предлагаемая тема обсуждения: «Какие возможности помогут пользователю быстрее выбрать фильм?». Сначала участники свободно предлагают идеи без критики, затем идеи группируются и оцениваются по полезности и реализуемости.

Дату, длительность, формат встречи и фактический состав участников нужно заполнить после проведения обсуждения. Если оно ещё не состоялось, раздел является планом.

2. Перечень идей для обсуждения

Поиск по названию; фильтр по жанру и году; сортировка по рейтингу; фильтр по длительности; подбор по настроению; персональные рекомендации; карточка фильма; сохранение «посмотреть позже»; история оценок; подборка случайного фильма; похожие фильмы; тёмная тема; адаптация под мобильный экран.

3. Группировка и отбор

Поиск и фильтры помогают сузить список. Карточка фильма предоставляет сведения для сравнения. Персонализация учитывает предпочтения. Сохранение фильмов поддерживает повторное использование сервиса.

Предварительно высокий приоритет имеют поиск, список фильмов, фильтр по жанру, карточка фильма и рекомендации по выбранным предпочтениям. Список сохранённых фильмов можно отнести к следующему этапу.

4. Итоговые функциональные требования

| ID | Требование | Приоритет | Потребность |
| --- | --- | --- | --- |
| FR-01 | Список фильмов с основной информацией | Высокий | Сравнение вариантов |
| FR-02 | Поиск по названию | Высокий | Быстрый поиск |
| FR-03 | Фильтр по жанру | Высокий | Сузить выбор |
| FR-04 | Сортировка по рейтингу | Средний | Сравнить варианты |
| FR-05 | Карточка фильма с описанием, годом, жанрами и рейтингом | Высокий | Решение о просмотре |
| FR-06 | Подборка по выбранным предпочтениям | Высокий | Персональные варианты |
| FR-07 | Список «посмотреть позже» | Средний | Сохранить интересные фильмы |
| FR-08 | Сообщение при отсутствии результатов | Средний | Понять, почему список пуст |

FR-01: система отображает список фильмов с основной информацией.

FR-02: пользователь может искать фильм по названию.

FR-03: пользователь может фильтровать фильмы по жанру.

FR-04: пользователь может сортировать результаты по рейтингу.

FR-05: карточка содержит название, описание, год, жанры и рейтинг, если данные доступны.

FR-06: система предлагает подборку на основе выбранных предпочтений.

FR-07: пользователь может сохранять фильм в список «посмотреть позже», если функция включена в объём проекта.

FR-08: при отсутствии результатов система сообщает об этом и предлагает изменить критерии.

5. Связь требований с аудиторией

Поиск и фильтры сокращают время выбора. Карточка помогает оценить вариант. Персональные подборки помогают находить новые фильмы, а сохранение — возвращаться к ним позже.

6. Контрольные вопросы

1. Мозговой штурм — групповая техника генерации идей.

2. На этапе генерации критика ограничивается, чтобы не подавлять предложения.

3. Функциональное требование описывает действие или возможность системы.

4. Потребности аудитории задают содержание и приоритет функций.

5. Фиксация всех идей сохраняет варианты для дальнейшего рассмотрения.

7. Вывод

Сформирован предварительный набор функциональных требований. Перед сдачей нужно подтвердить, какие идеи реально обсуждались, и приложить фото или скриншот доски обсуждения, если он есть.
